# TTS、视频预览、搜索与批量下载

## AI 自然配音

启动根目录 `scripts/start-tts.ps1`，或 `scripts/start.ps1 -WithTts`。默认连接同级既有 `gpt-sovits-cpu` 项目，页面显示就绪后可选择 16 种预置音色、试听参考音，调整速度与段间停顿，输出 MP3/WAV。每次最多 1000 字；先用短文测试 CPU 速度。模型与声音参考的来源由独立语音项目管理。

平台提交后记录引擎任务 ID，轮询分段状态，并将结果写入私有文件中心。提交超时且结果未知时禁止直接重试，以免重复生成；需要先到语音引擎核对。取消会向语音引擎发送取消请求，模型可能在当前片段结束后才停止。

“文字转语音”保留 eSpeak NG 基础离线音色，可设置中文/英语、语速、音调、音量及 WAV/MP3，不依赖模型服务。

## 搜索与下载

1. 打开“视频下载”，选择哔哩哔哩或 YouTube，输入关键词。
2. 勾选结果，点击“批量下载”；也可切换“粘贴链接”，每行一个地址。
   可选最高画质、1080p、720p、480p 上限。推荐先试 720p，减少下载体积；源站格式与网络仍会影响速度。
3. 每批最多 20 条，每条创建独立任务；重复链接跳过，格式错误的条目单独返回原因。
4. 当前页面显示下载状态；关闭弹窗仍在后台执行，可在任务中心取消、重试，完成后预览或下载文件。

每个账号默认最多 25 个活动任务，下载 Worker 并发 2。单文件上限 100 MB，单账号空间默认 2 GB。批量请求使用幂等键，响应丢失后同键重试不会重复创建已受理任务。搜索单独使用 `toolbox-search` 队列，结果保留 15 分钟且只能本人读取；每账号最多 6 次搜索/分钟。

搜索结果可见并不保证源站允许下载：登录、区域、付费、反自动化限制可能导致失败。当前网络实测 YouTube 搜索可用，但部分视频下载要求登录验证。系统显示失败原因，不自动提供账号 Cookie 或绕过访问限制。

## 预览

已下载文件的入口：

- 任务中心：列表、卡片和看板中的有文件结果任务均显示“预览”，直接打开独立播放窗口。
- 视频下载：本次下载结果点击“预览”打开播放窗口；关闭播放器返回下载窗口。重新打开下载工具后，可点击“查看已下载文件与播放预览”进入文件中心。
- 文件中心：点击文件卡片的“预览视频”或“试听音频”。

任务结果和文件中心支持音频/视频原生播放器，使用登录态与归属校验，支持 HTTP Range 拖动进度；不会将 MinIO 桶设为公开。浏览器不支持某种编码时可下载后用本地播放器打开。

2026-09-24 入口修复验证：前端构建通过，`node tests/toolbox/preview-entry-check.mjs` 的 5 项检查通过。使用已有视频验证三种任务视图、下载结果播放窗口、播放与跳转、Esc 关闭、文件中心入口及手机播放。下载结果回执在测试中模拟，实际播放器使用已有私有文件；未创建新下载任务。记录位于 `artifacts/preview-entry-check.json`。

API：`POST /api/video-search`、`GET /api/video-search/{id}`、`POST /api/video-downloads/batch`、`GET /api/assets/{id}/preview`。完整字段以 `/api/openapi.json` 为准。

批量接口新增可选 `quality` 字段（`best`、`1080p`、`720p`、`480p`），默认 `best`。调优参数与实测结果见 [下载性能说明](download-performance.md)。
