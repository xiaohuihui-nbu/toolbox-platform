# 任务管理与多视图

进入“任务中心”可切换列表、卡片、看板。视图偏好按平台账号保存在当前浏览器，刷新后保留。三种视图共用名称/完整 ID 搜索、状态筛选、工具筛选、创建时间排序与分页，每页 24 条；看板只对当前页结果分组，不提供手工拖拽改状态。

## 增删改查

- **新增**：点击“新建任务”，选择工具填写参数；视频下载支持搜索勾选和粘贴链接批量提交。
- **查看**：点击任务名称或详情，查看状态、失败原因、时间、输入快照和成果；音视频结果可直接预览。
- **修改**：本人任务均可改名称。只有 queued 状态允许修改输入参数，使用 JSON 编辑并由工具 Schema 校验；后台已领取则返回 409，不覆盖执行中的输入。
- **删除**：删除等待中或已结束任务的记录，已生成文件保留并解除任务关联。运行中/取消中的任务须先等待停止。界面要求确认，删除记录不可恢复。
- **批量删除**：列表、卡片、看板均可勾选，支持全选本页可删除任务（每页 24 条）、清空选择。切换视图保留选择，切换页码或筛选清空选择。确认弹窗列出任务名称和短 ID；后端重新校验状态，逐项返回删除/跳过结果。运行中、取消中的任务跳过，不影响同批其他可删除任务。生成文件保留，队列中尚未执行的任务不再处理。
- **取消/重试**：详情页提供相应按钮。重试创建新任务，保留旧记录；外部引擎提交结果未知时仍拒绝自动重复提交。

后端对查看、查询、修改和删除均校验归属，管理员也不能直接操作其他成员私有任务。编辑与删除锁定任务行，与 Worker 领取和提交结果串行处理；晚到的旧队列消息不会重建已删除任务。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/jobs` | 新建，携带 Idempotency-Key |
| GET | `/api/jobs` | 兼容原有数组列表 |
| GET | `/api/jobs/query` | 返回 items/total/page/page_size，支持 q/state/tool_id/sort |
| GET | `/api/jobs/{id}` | 本人详情，包含 params/tool_version |
| PATCH | `/api/jobs/{id}` | title 和/或 params |
| DELETE | `/api/jobs/{id}` | 成功 204，运行中 409 |
| POST | `/api/jobs/batch-delete` | `{"job_ids": ["UUID", ...]}`，1～100 个 ID，自动去重，返回 `deleted_ids` 和 `skipped` |

批量删除在一个事务中按 ID 顺序锁定本人任务行，删除可处理任务及其 outbox，并解除文件关联。`skipped` 每项包含 `id/code/message`，`active` 表示执行中，`not_found` 表示记录不存在、已删除或不属于本人（不暴露他人记录）。重复提交已删除 ID 会返回跳过，不会重复产生副作用。格式错误、空数组、超过 100 项或额外字段返回 422，未登录返回 401。遇到网络失败，确认窗口保留以便重试。

改输入参数会更新该任务的请求摘要；旧参数用相同幂等键重发将产生冲突。删除记录也会删除对应幂等记录；后续再次提交视为新任务。

测试：`backend/tests/toolbox/job_management.py`、`frontend/web/tests/toolbox/tasks-check.mjs`。前者使用隔离账号并清理数据，后者保留生成的文本样例文件用于检查删除后文件保留。

批量删除界面验收：`cd frontend/web && npm run test:batch-delete`，覆盖多视图勾选、部分选中、全选、取消确认、筛选清空、网络失败后重试、实际删除及下载文件保留。只删除本次生成的样例任务，保留样例文本文件。分页检查在当前任务数量超过一页时执行。
